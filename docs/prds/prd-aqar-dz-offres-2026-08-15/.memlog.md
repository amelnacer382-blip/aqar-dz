- (decision) Catalogue : 3 offres definies EN CODE (Starter/Pro/Enterprise), alignees sur la page tarifaire publique deja en ligne. Motif : les tarifs bougent rarement ; une table Plan editable est un cout de migration et d'ecrans que le MVP ne justifie pas. Arbitrage Bilal, 15-08-2026.
- (decision) Le choix : l'inscrit DEMANDE une offre depuis la page tarifaire, le super admin ARBITRE a l'approbation. Deux champs distincts, jamais confondus. Motif : sans arbitrage, n'importe qui s'auto-attribue Enterprise ; sans demande, l'intention du visiteur est perdue. Arbitrage Bilal, 15-08-2026.
- (decision) Quotas DURS sur biens et utilisateurs : la creation est refusee au-dela, avec un message qui nomme l'offre et le plafond. AUCUNE suppression retroactive : une agence retrogradee garde ce qu'elle a, elle ne peut plus ajouter. Motif : sans contrainte reelle l'offre est une etiquette ; avec suppression retroactive elle devient destructrice. Arbitrage Bilal, 15-08-2026.
